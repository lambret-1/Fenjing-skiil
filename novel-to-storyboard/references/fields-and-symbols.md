# 输出模板：字段、写法与符号

一条 Clip 就是一份完整产物，复制即用。结构固定，顺序不可变。

## 一、整体结构

```text
@图片1 = 素材名称
@图片2 = 素材名称
……

【人物与场景】
场景 @图片1：……
人物名 @图片2：……；本条状态：……
无图人物：年龄，五官，服装；本条状态：……
本条在场：……

【镜头1】
焦距：……mm ……，……景深
机位：…… + ……
构图：……
运镜：……，……
景别：……
画面：……
台词：说话人+语气+说{……}
视线落点：……
焦点：……
音效：<……>

【镜头2】
……

<环境音……>
（配乐……）

【约束】
1. ……
2. ……
```

## 二、@图片N

- 只列本条实际上传的素材，按上传顺序连续编号，不跳号、不空号。
- 编号由 `render_sd2.py` 按 `clip.assets` 顺序自动生成，人不手写。
- 最多 9 张，推荐 4–5 张。

## 三、【人物与场景】

位置：`@图片N` 之后、【镜头1】之前。每条 Clip 必须重写，不许「同上条」。

顺序固定：**场景 → 人物（按出场顺序）→ 本条在场**。风格与音色都不在这块里：风格自动并进【约束】第一条，音色不写，语气写在每句台词上。

### 场景行

```text
场景 @图片1：地点类型与空间层次，时间，光线与主光源
```

只锁空间与光，**不写人物站位**；站位写在镜头画面里。场景固有道具并进地点描述，不单列；`scene.props` 只用于管理，不参与渲染。

### 人物行（有参考图）

```text
沈知微 @图片2：年龄感，发型，服装主色与轮廓，体型，标志性特征；本条状态：……
```

- 身份部分只写不变项：年龄感、发型、服装主色与轮廓、体型、配饰、疤痣手绳。
- 本条状态写本条会变的：衣角沾泥、淋雨、受伤、换装、手持物、姿态。
- 身份特征 2–4 项，多了互相稀释权重。
- 不写音色。音色属于配音参考，不进锚点；情绪与口气一律写进台词行的语气状语。

### 人物行（无参考图）

```text
伙计：二十来岁，圆脸，左眉一道疤，灰布短打；本条状态：站在跳板口，肩搭毛巾
```

不写 `@图片N` 就是无图，不加任何标记。无图人物必须写全**年龄 + 五官/体貌 + 服装**三项，缺一项校验提醒。无图人物只建议用在远景、全景、中景；近景与特写必须有图，否则脸会飘。

### 本条在场

```text
本条在场：沈知微、老周
```

管的是这条片子允许谁出现。多人场景里防止模型把不在场的人塞进来；与【约束】里的「禁止同款分身」不是一回事，两条都要。

### 风格去哪了

风格不再单独占一行，由渲染器自动写进【约束】第一条：

```text
1. 整体画面为1930年代江南，民国写实，冷灰绿低饱和，胶片颗粒，16:9 画幅
```

章级 `style` 定义一次，每条自动带入；用户约束里已有同款风格词时不重复添加。

## 四、镜头十行

| 行 | 写法 | 作用 |
|---|---|---|
| 焦距 | `35mm 广角，中景深` | 决定透视与景深 |
| 机位 | `沈知微 + 背后平视跟随` | 机位对着谁、高度、角度 |
| 构图 | `中心构图` | 导演字段；同时必须在画面里写出实际位置 |
| 运镜 | `跟拍，手持微晃` | 一镜只允许 1 种；稳定度并入此行 |
| 景别 | `中景` | 强信号，决定人物占比 |
| 画面 | 五要素齐全的一段 | 唯一的主体描述；`visual.props` 若已在动作句出现则不重复渲染 |
| 台词 | `老周扯着嗓子说{……}` | 单独成行；说话人后必须带语气；一句一段不合并；空镜写 `{}` |
| 视线落点 | `前方雾中` | 眼神方向 |
| 焦点 | `锁定沈知微背影` | 对焦对象 |
| 音效 | `<……>` | 有值才输出此行 |

### 台词行

```text
台词：林峰压低嗓子说{车上有定位。}
```

- 格式固定：`说话人 + 语气状语 + 说{}`，语气必须写，缺了判硬伤。
- 语气是**状语**，2–8 字，能直接接在「说」前：`压低嗓子`、`冷冷地`、`试探着`、`一字一顿地`、`喘着气`。
- 不写动作。动作（抬头、关门、敲桌）归画面，语气只留声音状态。
- **一句一段，不合并。** 原文有几句话就写几个 `{}`，同一镜里用「；」分隔；每句单独给语气，不要把「补一句」的节拍压掉。
- 全条语气不能只有一个值，两句以上全同会报提醒。
- 画外心声：加 `voiceover: true`，渲染为 `林峰画外低声说{……}`，不做口型。
- 语气值池见 `references/tone-lexicon.md`。

### 稳定性并入运镜

JSON 里保留 `stability` 字段，渲染时不单独出行：

- 稳定 / 三脚架稳定 / 云台稳定 → 不标，只写 `运镜：固定镜头`
- 微晃 → `运镜：跟拍，手持微晃`
- 步伐微晃 → `运镜：跟拍，步伐带轻微晃动`
- 手持晃动 → `运镜：手持跟随，手持晃动`

「固定镜头（稳定）」这种重复写法禁止。

## 五、画面五要素（硬规则）

每一镜的画面必须自足：拿掉其他镜头、拿掉其他块，它自己就能拍。

1. **空间**：人在画面哪个位置、朝哪、离关键物多远。
2. **动作**：身体哪个部位在动、幅度多大、速度多快。
3. **环境**：前景、中景、背景各是什么；雾、雨、尘、人群。
4. **光**：光从哪来、明暗关系、有没有投影。
5. **道具**：手上、身边的关键物件，以及它和身体的接触关系。

缺任何一项，`--check` 判硬伤。字数预算 60–150 字；靠具体名词和方位，不靠形容词堆砌。

### 转移动作（跨镜硬规则）

人物换空间（车内→车外、门内→门外、岸上→船上），必须在画面里给出可见的转移动作：`推开车门跨下去`、`迈过门槛`、`一脚踏上跳板`。可以并进同一镜，但不能让观众脑补。

- 校验器会比对同一人物前后两次出现的空间词，中间没有转移动词就判硬伤。
- 同一镜内先因后果：不能先写「人已站在车门外」，再写「把车门关上」。

## 六、人物命名规则

- 在【人物与场景】定义过的：镜头正文**只写名字**，不写「年轻女子」「老船夫」这类描述，也不重复 `@图片N`。
- 没定义过的：首次出现处写全锚点——年龄、五官或体貌、服装，例如 `杂货铺伙计，二十来岁，圆脸，左眉一道疤，灰布短打`。
- 跨条出现的临时人物一律提升进【人物与场景】，哪怕没有图，用纯文字锚点。
- 名字全章唯一，不得中途换名；校验器会检查台词说话人是否在 cast 里。

## 七、符号与括号

| 符号 | 唯一用途 |
|---|---|
| `{}` | 台词 |
| `<>` | 音效 |
| `（）` | 配乐，全篇只出现在段尾那一行 |
| `【】` | 结构标题 |

其余一律不用括号。人物锚点、状态用逗号、分号、冒号断开。`｜` 禁用。

校验器会逐行扫描：全角括号出现在非配乐行、花括号出现在非台词行、尖括号出现在非音效行，全部判硬伤。

## 八、禁止依赖记忆的表述

视频生成没有记忆，每次调用都是无状态的。所以：

- 禁止「承接上条」「同上」「如前」「延续上段」「继续上一句」。
- 台词跨条时，下条必须重写说话人与语气。
- 每条的人物、场景、约束（含风格）全部重写，不引用其他条。

## 九、与旧模板的差异

| 项目 | 旧版 | 现版 |
|---|---|---|
| 镜头行数 | 11 行（稳定性单列） | 10 行（稳定性并入运镜） |
| 人物关系块 | 【人物关系与构图逻辑】 | 删除；排他并入 `本条在场`，首镜构图基准写进画面 |
| 人物描述 | 可用描述性代称 | 只用名字；未定义才写全锚点 |
| 锚点 | 无 | 新增【人物与场景】，每条重写 |
| 括号 | 混用 | 四套符号各司其职 |
| 风格 | 单独一行 | 并入【约束】第一条 |
| 音色 | 人物行内 | 删除；语气写进台词 |
| 台词 | `老周说{}` | `老周扯着嗓子说{}` |
| 承接 | 文本承接 | 每条自包含，禁止跨条引用 |
