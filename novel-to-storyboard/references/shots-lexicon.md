# 镜头语言值池

只提供取值范围，不提供固定搭配。选值是判断，不是轮盘。

## 焦段与景深

| 焦段 | 类型 | 适用 | 常见景深 |
|---|---|---|---|
| 14–18mm | 超广角 | 极端空间、压迫、狭小室内 | 深 |
| 21–24mm | 广角 | 环境交代、大远景、跟拍 | 深 |
| 28–35mm | 小广角 / 广角 | 中景跟拍、纪实感 | 中 |
| 50mm | 标准 | 平视对话、自然视角 | 中 |
| 85mm | 中长焦 | 近景、人物半身、压缩空间 | 浅 |
| 100–135mm | 长焦 | 特写、偷窥感、强压缩 | 极浅 |
| 200mm | 超长焦 | 远距离压缩、细节隔离 | 极浅 |

## 景别

大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写。

选择依据是“观众该看多少”：看空间用大远景，看关系用全景，看动作看中景，看情绪看近景，看细节看特写。

## 运镜（一镜只允许 1 种）

固定镜头、跟拍、背跟、侧跟、手持跟随、横摇、上下摇、横移、纵深推进、慢推、急推、慢拉、急拉、升、降、环绕、变焦、甩镜。

禁止组合写法：`推镜+横摇`、`边推边摇` 一律判硬伤。

## 机位

高度：贴地 / 低机位仰拍 / 平视 / 略高俯拍 / 高机位俯拍 / 顶俯。

角度：正面 / 正侧面 / 背侧45° / 背后跟随 / 过肩 / 反打 / 侧面跟随 / 远眺。

机位行写「对着谁 + 高度 + 角度」，例如 `沈知微 + 背后平视跟随`、`栈桥全貌 + 平视远眺`。

## 构图

中心构图 / 三分法 / 对角线构图 / 引导线构图 / 框架构图 / 对称构图 / 大面积留白 / 前景遮挡 / 黄金分割 / 重复韵律 / 无明确构图。

构图是导演字段，**输出保留，但画面里必须写出实际位置**：`沈知微位于画面中央偏右，栈桥在画面右上角拉出斜线`。只写术语不写位置，模型照样排错。

## 稳定度

稳定 / 三脚架稳定 / 云台稳定 / 呼吸感微动 / 步伐微晃 / 微晃 / 手持晃动 / 剧烈晃动。

渲染时并入运镜行；稳定类不标，晃动类附在逗号后。

## 防写死六条

1. **不按镜头序号轮换景别。** 相邻两镜同为中景不是错，无理由的变化才是错。
2. **不套固定配方。** 「远景建立 + 中景对话 + 特写反应」是常见结构，不是每场都必须。
3. **焦段跟着空间走。** 房间小就用广角，人物远就用长焦；不要为了“电影感”全片上 85mm。
4. **运镜跟着信息走。** 有新信息才推，有离开才拉，有追随才跟；固定镜头能讲清就别动。
5. **构图术语必须落到位置。** 三分法要写出主体压在哪条线上，引导线要写出线从哪到哪。
6. **情绪不外挂形容词。** 「唯美」「氛围感」「高级感」一律删，换成光、雾、材质、动作。

## 三套常用组合（可抄，但别每场都抄）

**建立段**：24mm 广角深景深 + 大远景 + 固定镜头或缓慢横移 + 引导线构图

**对话段**：35–50mm 中景深 + 中景 / 中近景 + 固定镜头 + 三分法，过肩或正侧面

**压迫段**：85mm 浅景深 + 近景 + 缓慢推近 + 中心构图，低机位略仰
