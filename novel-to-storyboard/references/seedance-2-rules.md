# Seedance 2.0 硬规则

目标模型：豆包 / 即梦 Seedance 2.0。以下均为官方口径，写错会直接掉画质或触发异常。

## 一、参数表

| 项目 | 规格 |
|---|---|
| 单条时长 | 5–15 秒（豆包工具区间；API 为 4–15 秒） |
| 镜头时间戳 | 不支持，只认「镜头1 / 镜头2」序号 |
| 图片参考 | 最多 9 张，推荐 4–5 张，不要塞满 |
| 视频参考 | 最多 3 段，总时长 ≤15 秒 |
| 音频参考 | 最多 3 段，总时长 ≤15 秒 |
| 画幅 | 16:9 / 9:16 / 4:3 / 1:1 / 3:4 / 21:9；默认 16:9，短剧用 9:16 |
| 多镜头 | 支持 15 秒高质量多镜头音视频连续输出 |
| 台词语言 | 全篇统一，不中英混用（专有名词除外） |

## 二、四条铁律

1. **提示词里不写任何秒数**：`0–3s`、`3–7秒`、`第 4 秒` 全部禁止。
2. **一个镜头只写 1 种运镜**，不同时要推、拉、摇、移。
3. **台词只用 `{}` 包裹**，不写进画面句，不用引号代替。
4. **一条提示词只服务一条 Clip**，不把整章剧本塞进一段。

官方原话：模型对精确时间的支持不稳定，强行限制时长可能导致生成异常；不强制每段时长，优先让模型按剧情自然生成节奏。

## 三、符号表（全篇只有四套）

| 符号 | 唯一用途 | 允许出现的位置 |
|---|---|---|
| `{}` | 台词 | 台词行 |
| `<>` | 音效 | 镜内音效、段尾环境音 |
| `（）` | 配乐 | 段尾配乐，全篇仅此一处 |
| `【】` | 结构标题 | 【人物与场景】【镜头N】【约束】 |

其余一律不用括号：人物锚点、状态用冒号和分号断开，图号只用 `@图片N`。竖线 `｜` 全篇禁用。

## 四、素材规则

- **每次生成按本次实际上传顺序连续编号** `@图片1`…`@图片N`，禁止跳号。渲染器自动编号，不要手写。
- 人物参考默认用**全身照**，脸要清晰；脸太小补一张**半身照**（腰以上）。**不用大头照、不用三视图/多视图**——多视图会被识别成多个主体，加剧换脸与双胞胎。
- 重要素材前置：越需要精准参考的图，在提示词里越靠前。
- 参考图不要带文字、字幕、水印；有就先处理掉再上传。
- 一张图里人物不超过 4 个，超过稳定性明显下降。
- 用户提供的人物图、场景图、道具图优先级最高；与文字锚点冲突时以图为准改锚点，文本里的标志性特征（疤、痣、手绳）必须保留并单列。

## 五、约束词（每条 Clip 必须带全）

```text
保持无字幕，避免生成任何文字或字幕
台词仅人声，画面不出现字幕文字
不要生成 Logo、水印
画质保持高清，细节丰富，光影柔和，人物面部稳定不变形
禁止同款分身或双胞胎
```

缺任何一条，渲染器的 `--check` 判硬伤。

## 六、官方进阶公式

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

本 Skill 的十行镜头字段就是这条公式的逐项落位：

- 精准主体 → 【人物与场景】+ 画面句首的名字
- 动作细节 → 画面（肢体部位、幅度、速度、力度）
- 场景环境 → 画面（前景/中景/背景）
- 光影色调 → 画面（光从哪来、明暗、投影）+ 约束第一条的风格
- 镜头运镜 → 焦距 / 机位 / 构图 / 运镜 / 景别
- 视觉风格 → 约束第一条（渲染器自动生成）
- 画质 → 【约束】
- 约束条件 → 【约束】

## 七、高频坑

| 现象 | 改哪里 |
|---|---|
| 人物不像、主体漂移 | 换全身照、脸清晰、补半身照；重要素材前置；删掉多视图 |
| 画面出现双胞胎 | 加防双胞胎约束；参考图用单人照；精简提示词 |
| 画面烧字幕 | 台词留在 `{}`，清掉参考图里的文字，加无字幕与仅人声约束 |
| 出现 Logo / 水印 | 补 Logo 与水印约束 |
| 动作僵硬 | 改低缓连续小动作，写肢体部位与幅度 |
| 镜头太碎 | 合并到 2–4 镜，只保留有信息增量的切点 |
| 对白塞不下 | 声音跨镜不删句，或按句号/破折号拆条 |
| 多人分不清谁说话 | 写明谁说话、谁只反应，焦点给说话者 |
| 风格漂移成动漫 | 参考图与提示词都锁写实 |
| 片尾杂音 | 后期末尾音量拉到 0 做淡出，不写进提示词 |
| 台词读错 | 生僻字、多音字换成发音一致的常用字 |
