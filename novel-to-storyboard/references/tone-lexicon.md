# 语气值池

台词只写「林峰说{……}」太单调，模型也拿不到表演指令。每句台词必须带语气状语，写在说话人和「说」之间。

## 写法

```text
台词：林峰压低嗓子说{车上有定位。}
台词：阿诚试探着说{不问出点什么。}
台词：老周扯着嗓子说{上船喽——过河的抓紧，雾要变天。}
```

- 语气是**状语**，2–8 字，能直接接「说」。
- 不写动作：抬头、关门、敲桌归画面，语气只描述声音状态。
- 一句一段，不合并；原文几句就写几行，语气可以重复。
- 两句以上台词语气全同，校验会报「全条语气单一」。

## 值池（按情绪取，不要轮着抄）

| 情绪 / 状态 | 可用的语气状语 |
|---|---|
| 冷淡、疏离 | `冷冷地` `淡淡地` `不带情绪地` `平声` |
| 压低、保密 | `压低嗓子` `压着声` `贴着气声` `凑近了低声` |
| 试探、不确定 | `试探着` `迟疑地` `半信半疑地` `尾音上扬` |
| 强硬、命令 | `硬声` `不容置疑地` `咬着字` `一字一顿地` |
| 急促、焦急 | `急声` `抢着说` `喘着气` `上气不接下气` |
| 讥诮、讽刺 | `讥诮地` `皮笑肉不笑地` `拖着长音` `凉凉地` |
| 温柔、安抚 | `放软了声` `轻声` `温声` `放缓语速` |
| 疲惫、虚弱 | `有气无力地` `哑着嗓子` `断断续续地` |
| 压抑怒火 | `压着火` `从牙缝里挤出来` `沉声` |
| 慌乱、心虚 | `干笑一声` `磕巴着` `声音发飘` |
| 决绝、摊牌 | `平静得反常地` `把话咬死` `不再留余地地` |

## 画外心声

不开口、只有声音的台词，加 `voiceover: true`，渲染成：

```text
台词：林峰画外近乎无声地说{退役军人。}
```

画面里可以保留唇形动作，但声音走画外，不做同步口型。旁白、电话音、广播音同样处理。

## 同一句话，四种语气

```text
林峰说{问不出来。}
林峰冷冷地说{问不出来。}
林峰压低嗓子说{问不出来。}
林峰一字一顿地说{问不出来。}
```

字没变，表演完全不同。这就是语气行的作用。

## 反例

- `林峰平静地说{……}` 连用五句：等于没写，且会触发「语气单一」提醒。
- `林峰说{……}，语气很冷`：语气跑到了括号外，格式错。
- `林峰冷笑着，把烟摁灭，说道{……}`：动作混进语气，句子变长，模型反而抓不住声音状态。
- `林峰用冷酷无情的声音说道{……}`：形容词堆砌，改成 `冷冷地`。
