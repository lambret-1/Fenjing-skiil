# 章节流水线：从整章小说到 15 秒 Clip

按顺序执行，不跳步。前一步的输出是后一步的输入。

## Step 0 原文清洗

进入任何统计前先清洗：

- 剥离章节标题、作者有话说、分隔线、平台水印文字、括号内非叙事内容。
- 保留对白引号、省略号、破折号、感叹号——它们决定停顿预算。
- 无法归属的说话人标为「未知说话人」，不猜。
- 标记暴力、血腥、政治、未成年人不当内容的段落，进入敏感分级。
- **原文没有的台词、关键动作、人物不得虚构。** 允许补的只有：环境细节、镜头语言、不改变因果的过渡动作。
- 不把旁白改成对白，不把对白改成旁白。
- 不把整段原文塞进提示词：删掉不进入画面的心理描写与剧情解释，只留可拍的部分。

### 敏感内容分级

| 级别 | 情形 | 处理 |
|---|---|---|
| 1 暗示 | 暴力、血腥、伤害过程 | 保留结果与反应，过程改为暗示：切旁观者表情、影子、血迹特写 |
| 2 删改 | 具体施暴步骤、自伤方式、未成年人不当描写 | 删除可执行细节，只保留剧情必要的关系与后果 |
| 3 拒绝 | 涉及政治敏感、色情、教唆犯罪 | 停止该段分镜，说明原因，不出提示词 |

## Step 1 章级发声台账

逐句提取所有**会出声的内容**：对白、旁白、内心独白、系统提示音、广播、电话音、短信朗读。

只统计会发声字符；动作描写、环境描写不计入。


## Step 2 语速与时长规划

### 语速表

| 场景类型 | 字/秒 | 说明 |
|---|---|---|
| 常态对话 | 4.0–4.8 | 自然交谈 |
| 旁白叙述 | 3.8–4.5 | 偏稳，句尾留气 |
| 情感独白 / 慢内心戏 | 3.0–4.0 | 允许拖音与长停顿 |
| 急喊 / 爆发 / 短促冲突 | 4.8–5.5 | 仅限原文明确支持 |
| 电话 / 广播音 | 4.2–5.0 | 略带失真 |

有参考配音时用 10 秒样音实测，偏差超过 15% 按实测值重算。

### 时长计算（并行取最大，不叠加）

```text
单句发声时间 = 该句可发声字数 ÷ 语速
发声轨 = Σ 单句发声时间 + Σ 标点停顿 + Σ 换人间隔
画面轨 = Σ 动作时间 + 空镜/建立镜头 + 转场呼吸（与台词并行的动作不重复计）
单条时长 = max(发声轨, 画面轨) + 0.5–1.5 秒收束余量
```

停顿预算：逗号 0.1–0.2 秒；句号 0.3–0.4 秒；省略号或未尽语气 0.4–0.6 秒；关系变化后的反应 0.3–0.8 秒。

整章视频时长 = 各条时长之和，**不要把发声轨与画面轨相加**。

### 拆条规则

- 先划回合，再算时长：一问一答、一个动作收束才算一个回合；切点落在回合结束处，不切在反应镜头中段。
- 15 秒是上限，不是目标；不许为凑满时长加无声反应镜头，宁可短。
- 单条超过 15 秒时在**切点**处拆，不在句子中间硬断。
- 一条完整话轮可以跨多条，但不为凑时长删句、改句、拆碎语意。
- 台词整句不拆：切点落在句号或破折号后；下条必须重写说话人与语气。
- 一句台词一个 `{}`，不合并同说话人的连续句；原文的停顿与「补一句」都要保留。
- 末条不足 5 秒时合并到上一条；不要用静默镜头垫时长。
- 条尾必须是台词、动作完成或钩子，不能是同人同机位的静默近景。
- 条首不得复用上条末镜的人物、机位、景别：换人、换角度或换景别。
- 换空间必须给可见转移动作：下车、推门、迈步、跨门槛、跳上船；可以在同一镜内完成，但不许让观众脑补。
- 同一镜内先因后果：不能先写「人已站在车门外」，再补「把车门关上」。
- 单镜承载台词超过约 24 个可发声字符（≈5–6 秒）时，让**声音跨镜**：声音不断，画面在本句内部切到反应或细节。

## Step 3 锚点体系

五类锚点各有可变范围，混在一起一致性必崩。

| 类型 | 定义位置 | 可变性 |
|---|---|---|
| 风格锚点 | 章级，只定义一次 | 全章不变 |
| 身份锚点 | 章级，终身不变 | 年龄感 + 发型 + 服装主色与轮廓 + 体型 + 标志性特征 |
| 状态锚点 | 每条 Clip 的 states | 换装、受伤、淋雨、哭过、情绪转折时新建 |
| 场景锚点 | 章级，只锁空间 | 不写人物站位；换时间/光线时新建一条 |
| 语气锚点 | 每句台词 | 逐句写语气状语；全条不能只有一个语气 |

规则：

- 身份锚点只写不变项，不写情绪、伤势、手里拿的东西。
- 状态锚点只在变化后的第一条 Clip 重建，后续条引用同一条状态。
- 场景锚点不写站位；站位写在每个镜头的画面里。
- 同一部剧的后续章节沿用同一套风格与身份锚点，只新增状态与场景，不重新发明；语气按每场情绪重写。

## Step 4 镜头切分

### 镜头数量

| 段落类型 | 镜头数 |
|---|---|
| 默认对话 / 叙事 | 2–4 镜 |
| 连续表演、独白、对峙、长镜头调度 | 允许 1 镜完成 |
| 动作、追逐、冲突爆发 | 4–6 镜 |
| 空镜转场、情绪留白 | 1 镜 |

**不设镜数配额。** 判断标准只有一个：这一段有没有新的观看内容。没有新内容的切镜就是废镜。

### 切镜资格

每次切镜必须能回答两个问题：

1. 为什么现在切？
2. 下一镜接住了什么？

答不上来就不切。允许的切点：动作完成、信息揭示、反应发生、空间转移、声音先行或延后。

**不机械轮换景别。** 相邻镜头景别相同不是错，无理由的变化才是错。

### 动作写法

- 肢体细化 + 程度量化：写到手、腿、头、肩背，并给幅度、速度、力度。
- 优先低缓连续的小动作：缓慢行走、轻轻抬手、顺势坐下；避开狂奔、大跳、剧烈翻滚。
- 写动作过渡：借着转身惯性顺势抬手，从停顿状态自然过渡到举手。
- 情绪外化：不写「很悲伤」，写身体细节。
- 道具动作先过现实性：按服装、口袋深度、双手占用和下一步意图设计拿、握、藏、放。

### 每镜必须写清的四件事

1. 运镜或切换方式，只写 1 种。
2. 主体动作与表情。
3. 位置与空间关系：谁在哪、朝向、和谁的距离。
4. 声音：环境声、动作音、音乐、人声。

## 附录：情绪外化对照

| 抽象情绪 | 外化成动作 |
|---|---|
| 悲伤 | 低头、肩膀微颤、眼眶泛红、手指无意识攥紧衣角 |
| 喜悦 | 嘴角上扬、眉眼舒展、脚步变轻快 |
| 紧张 | 频繁看表、手指敲桌面、呼吸急促、眼神闪躲 |
| 愤怒 | 双拳紧握、下颌绷紧、胸口起伏、从牙缝里挤话 |
| 释然 | 长舒一口气、肩膀放松、抬头望向远处 |
| 强撑镇定 | 手指扣住衣角、喉结动一下、声音压平但尾音发抖 |
| 心虚 | 眼神先落在对方肩上再移开、手去摸并不存在的口袋 |
| 崩溃 | 先笑一下、眼泪掉下来、肩膀塌下去、不出声 |
| 决绝 | 把东西放稳、站直、直视对方、语速放慢 |

## 附录：声音写法

| 类型 | 写法 | 禁止 |
|---|---|---|
| 环境声 | 「窗外车流压得很低」「雨声贴在玻璃上」 | dB、频谱、频段 |
| 动作音 | `<合上笔记本时一声轻响>` | 「第 4 秒」「第 12 帧」 |
| 情绪音 | `<心跳声几乎贴着耳朵>` | 具体 Hz |
| 音乐 | `（钢琴单音，冷调，人声段压低）` | 「-12dB ducking」 |
| 台词 | `说话人+语气+说{原文}` | 台词混进画面句、语气为空 |
