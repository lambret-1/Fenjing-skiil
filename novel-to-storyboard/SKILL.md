# 小说转分镜

把一章小说变成能直接喂给 Seedance 2.0 的分镜提示词。数据只有一份，产物只有一份。

## 定位

- 输入：整章小说、单场戏、已有剧本或旧分镜。
- 输出：一份章级 `chapter.json`，加一份 `分镜.md` 文档；文档里每段一个围栏块，复制即用。
- 规格：每条 Clip 15 秒，1–6 个镜头，16:9 默认。
- 不做：A/B 双层、首尾帧接续、视频延长。

## 唯一产物

- **数据层**：一份 `chapter.json`，章级锚点只定义一次，每条 Clip 通过引用取用。
- **文本层**：一份 `.md` 文档，固定结构：
  `# seedance2.0提示词` → `共X段，X个镜头，总时长：X秒` → `---` → `所需场景：…` → `所需人物：…` → 每段 `## 第X段，X个子镜头` + ```text 围栏。
- 围栏内是完整提示词：`@图片N = 名称` → 【人物与场景】→ 【镜头N】十行 → `<环境音>` → `（配乐）` → 【约束】。
- 渲染时锚点全量展开，不允许「同上条」「承接上条」。

## 工作流

### 1 清洗原文

剥离标题、作者注、分隔线、平台水印；保留引号、省略号、破折号。原文没有的台词、关键动作、人物不得虚构，只允许补环境细节、镜头语言、不改变因果的过渡动作。敏感内容按三级处理。

详见 `references/chapter-pipeline.md` Step 0。

### 2 建发声台账

逐句提取对白、旁白、内心独白、广播电话音，只统计会发声字符。输出总字数、可发声字数、各类句数、未知说话人、敏感标记。

### 3 语速与拆条

按场景类型取语速（常态 4.0–4.8 字/秒），用「发声轨与画面轨并行取最大」算单条时长，超 15 秒在句号或破折号后拆条。台词整句不拆。

### 4 定锚点

先确认用户有没有人物图、场景图、道具图；有就优先绑定，没有才按文本补全。章级定义四类锚点：风格、身份、状态、场景。身份锚点写 2–4 项稳定特征；状态按条写；场景只锁空间与光，不写站位；语气不设锚点，逐句写进台词。

详见 `references/chapter-pipeline.md` Step 3。

### 5 切镜头

按段落类型分配镜头数：默认 2–4，连续表演允许 1，动作段 4–6。每次切镜必须回答「为什么切、下一镜接住什么」。动作写肢体部位、幅度、速度、力度，优先低缓连续小动作。

### 6 写入 JSON

按 `assets/schema.json` 填 `assets/template.json`。章级字段填一次，每条 Clip 填：

- `scene`：场景 id
- `cast`：本条在场人物 id
- `assets`：本条实际上传的素材 id，按上传顺序排
- `states`：人物本条状态
- `ambience` / `music`
- `shots`：1–6 个镜头，每镜十行对应的结构化字段

### 7 渲染与校验

```bash
python3 scripts/render_sd2.py chapter.json --list
python3 scripts/render_sd2.py chapter.json --check
python3 scripts/render_md.py chapter.json -o 分镜.md
```

`--check` 必须 0 处硬伤才能交付；`render_md.py` 遇到硬伤会拒绝出文档。渲染器自动完成：`@图片1…N` 连续编号、锚点展开、稳定性并入运镜、约束编号去重、Markdown 文档头与小节标题。

## 硬边界

1. 提示词里不写任何秒数、时间戳，只写「镜头1 / 镜头2」。
2. 一个镜头只写 1 种运镜，禁止「推+摇」「边推边移」。
3. 台词只用 `{}` 并单独成行，说话人后必须带语气状语，如 `林峰压低嗓子说{……}`；一句一段不合并；画外心声加 `voiceover`；空镜写 `台词：{}`。
4. 一条提示词只服务一条 Clip，不把整章塞进一段。
5. 每镜画面必须自足，五要素齐全：空间、动作、环境、光、道具；缺项判硬伤。
6. 人物在【人物与场景】定义过的，正文只写名字；没定义过的，首次出现写全年龄、五官、服装。
7. 每条 Clip 重写全部锚点，禁止依赖记忆的表述。
8. 符号只有四套：`{}` 台词、`<>` 音效、`（）` 配乐、`【】` 结构标题；其余不用括号，`｜` 全篇禁用。
9. 图片 ≤9 张、推荐 4–5 张；案本条上传顺序连续编号，不跳号。
10. 敏感内容三级：暗示、删改、拒绝；三级直接停做并说明。
11. 长章超过 6 条 Clip 时按每批 3–5 条交付，先给章级概览与锚点。
12. 切条以回合为单位：一问一答一动作收束才算一个回合，切点落在回合结束处，不切在反应镜头中段。
13. 条尾不许静默垫片：末镜必须有台词、有动作完成或有钩子；不许用同人同机位的无声近景凑满 15 秒，宁可短。
14. 条首相接：本条首镜不得复用上条末镜的人物、机位、景别。
15. 换空间必须显式：下车、推门、迈步、跨门槛、跳上船，可以在同一镜内完成；不许让观众脑补，也不许先「人已在门外」再补「关门」。

## 输出格式速查

````markdown
# seedance2.0提示词

共3段，14个镜头，总时长：45秒

---

所需场景：别墅车库、别墅门廊
所需人物：阿诚、林峰

## 第1段，4个子镜头

```text
@图片1 = 别墅车库场景图
@图片2 = 阿诚定妆图

【人物与场景】
场景 @图片1：……
阿诚 @图片2：……；本条状态：……
本条在场：阿诚

【镜头1】
焦距：35mm 广角，中景深
机位：阿诚 + 平视正侧面
构图：三分法
运镜：固定镜头
景别：中景
画面：……
台词：阿诚压着嗓子说{送哪儿。}
视线落点：后视镜
焦点：锁定阿诚侧脸
```
````

围栏内字段写法与括号规则见 `references/fields-and-symbols.md`。

## 常见改法

| 用户说 | 改哪里 |
|---|---|
| 人物不像、漂了 | 换全身照脸清晰，补半身照，重要素材前置，删多视图 |
| 出现双胞胎 / 多出人 | 检查 `本条在场`，加防双胞胎约束，精简画面 |
| 画面糊、说不清 | 补五要素，重写画面，不堆形容词 |
| 动作僵硬 | 改低缓连续小动作，写肢体部位与幅度 |
| 节奏太碎 | 合并镜头到 2–4，只留有信息增量的切点 |
| 台词太平、像念稿 | 逐句补语气状语，全条不要同一个语气 |
| 台词塞不下 | 声音跨镜不删句，或按句号拆条 |
| 烧字幕 | 台词留 `{}`，清参考图文字，确认无字幕与仅人声约束 |
| 风格漂移 | 参考图与提示词同时锁写实 |
| 一条太长 | 拆条，不删戏；每镜压到 150 字内 |
| 两条接不上、像跳帧 | 末镜补收束动作或钩子，首镜换人/换角度/换景别，不靠同机位硬接 |
| 人物突然换了地方 | 补可见转移动作：下车、推门、迈步、跨门槛，可并进同一镜 |
| 要一份能直接发出去的文档 | `python3 scripts/render_md.py chapter.json -o 分镜.md`，一次出全章 |

## 交付自检

- [ ] `--check` 输出 0 处硬伤
- [ ] 交付件是 `.md` 文档，含标题、`共X段，X个镜头，总时长：X秒`、分割线、所需场景、所需人物
- [ ] 每段标题为「第X段，X个子镜头」，下面紧跟一个 ```text 围栏块
- [ ] 每条 Clip 有【人物与场景】，锚点逐条写全
- [ ] 每镜画面五要素齐全，有方位、有光、有环境或道具
- [ ] 人物统一用名字，未定义人物写全锚点
- [ ] 全文无秒数、无 `｜`、无「同上条」
- [ ] `@图片N` 连续，图片不超过 9 张
- [ ] 台词全部在 `{}` 内、单独成行，且每句都有语气
- [ ] 相邻两条：本条首镜没有复用上条末镜的人 + 机位 + 景别
- [ ] 每条末镜有台词、动作完成或钩子，没有静默垫片
- [ ] 人物换空间都有可见转移动作，没有先结果后动作
- [ ] 约束四条齐全：无字幕、仅人声、无 Logo 水印、面部稳定防双胞胎
